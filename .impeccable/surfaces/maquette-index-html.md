# Surface brief: maquette app (prototype cliquable)

Scope: prototype HTML des écrans clés de l'app (Accueil / vue générale, Opérations, Ajout rapide, Épargne + détail catégorie, Solde initial, Rappels & réglages). Mode: Operate.
Audience: utilisatrice unique, mobile d'abord, saisie quotidienne en FCFA. Constraints: violet #9518ad principal, français, light + dark.
Unresolved: catégories de dépenses définitives, budgets mensuels.

## Direction contract

THESIS: Le standard des apps de finances perso, sans ironie, au niveau Revolut / Wave / Monarch / Apple Wallet. Refuse le tableau de bord gadget saturé de widgets : une vue générale qui répond « où j'en suis ce mois-ci ».

OWN-WORLD: Fond clair légèrement teinté violet, une carte solde violet #9518ad plein, neutres tintés, une teinte fixe par catégorie d'épargne (Cotisations ambre, Banque bleu, Familiale corail). Geist, chiffres tabulaires, rayons 20/14/10, ombres douces décalées, icônes Lucide trait 1.75.

STORY: Elle ouvre, voit son patrimoine et le flux du mois, ajoute une dépense en 5 secondes, vérifie ses épargnes, reçoit un rappel.

FIRST VIEWPORT: Mobile : salutation + mois, carte solde violet (patrimoine total, revenus / dépenses du mois), barre d'épargne empilée 3 couleurs, rappel de mise à jour, dernières opérations. Barre d'onglets avec + central sous le pouce. Desktop : rail latéral, deux colonnes.

FORM: canon (standard de catégorie), choisi par l'utilisatrice ; seed 6bc54136. Signature : feuille d'ajout avec pavé numérique, courbe tiroir iOS.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
